## How to use:
- You will need the latest Visual Studio 2022 and the latest .NET Core 8.
- The latest SDK and tools can be downloaded from https://dot.net/core. Also you can run this Project in Visual Studio Code (Windows, Linux or MacOS). To know more about how to setup your enviroment visit the [Microsoft .NET Download Guide](https://dotnet.microsoft.com/en-us/download).
